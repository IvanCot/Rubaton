# Проверка разрешений при погашении RUBA

**RUBATON · трек Б «Безопасность»**

Клиент хочет погасить **5 000 RUBA**. Если запрос предложит разрешить списание **50 000 RUBA** или укажет другой модуль, кошелёк покажет расхождение и заблокирует подпись. Клиент вводит ожидаемую сумму в кошельке, а адрес разрешённого модуля кошелёк берёт из собственной конфигурации.

При успешной проверке эмитент применяет Permit, сжигает токены и перечисляет рубли. Оператор видит подтверждение сжигания, банковский статус и открытый долг. Сверка исходного перевода защищает от повторной выплаты при потере ответа банка.

## Демо за 3 минуты

1. На [портале клиента](http://127.0.0.1:4173) создайте заявку на **5 000 RUBA**. В кошельке введите `5000`, выберите эмитента и подтвердите разрешение.
2. На [экране оператора](http://127.0.0.1:4173/operator) нажмите **Применить Permit → Сжечь токены → Отправить выплату**. У клиента останется **55 000 RUBA**, на счёт поступит **5 000 ₽**, долг эмитента составит **0 ₽**.
3. В разделе **Управление стендом** сбросьте прогон и выберите **В запросе 50 000 RUBA**. При ожидаемых **5 000 RUBA** кошелёк покажет обе суммы и заблокирует подпись.

В том же разделе можно показать подмену адреса модуля, блокировку KYT, отказ банка и потерю ответа после выплаты.

## Запуск на Windows

Нужны Node.js 24 LTS (24.12+) и pnpm 11.25.0. При необходимости установите pnpm командой `npm.cmd install --global pnpm@11.25.0`.

```powershell
pnpm.cmd install --frozen-lockfile --ignore-scripts
node --run build
node --run start
```

После сборки стенд запускается офлайн. `Ctrl+C` останавливает сервер. `node --run test` запускает интеграционные тесты.

## Границы прототипа

Кошелёк создаёт подпись [ERC-2612](https://eips.ethereum.org/EIPS/eip-2612) вне сети. Разрешение применяется и токены сжигаются в локальной EVM. KYC, KYT и банк симулируются. В расчёте **1 RUBA = 1 ₽**, комиссия за погашение **0 ₽**. Перед пилотом нужно согласовать с командой RUBA формат разрешения, доверенный источник адресов и способ подтверждения банковской выплаты.

Знак RUBATON и иллюстрация «Безопасность» взяты со страницы 14 материалов хакатона.
